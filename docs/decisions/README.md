# Architecture Decision Records

There are no formal architecture decision records in this directory yet. The architecture pages describe observed implementation behavior; they should not be read as a complete history of why every choice was made.

For a material future decision, add a numbered Markdown record here with:

- **Status:** proposed, accepted, superseded, or rejected.
- **Context:** the problem and constraints.
- **Decision:** the selected approach.
- **Consequences:** trade-offs, migration needs, and follow-up work.

Keep the decision index current when adding records. Avoid retroactively assigning a rationale unless it is confirmed by the maintainers.
